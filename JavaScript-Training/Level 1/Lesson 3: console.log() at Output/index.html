Lesson 3 — console.log() at Output

Exercise 1 — Gamit ang Browser Console

Goal: Makapagpatakbo ng unang JavaScript code.

  1. Buksan ang Google Chrome..
  2. Pumunta sa kahit anong webpage.
  3. Pindutin ang F12.
  4. Piliin ang Console tab.
  5. I-type ang code sa ibaba.

Exercise 2 — Multiple output

Goal: Makapag-display ng maraming outputs.

Gumawa ng JavaScript code na magpapakita ng sumusunod:

  • Gumamit ng apat na console.log().
  • Isang statement para sa bawat line.
  • Siguraduhing tama ang spelling at punctuation.
