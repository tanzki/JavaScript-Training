      <html lang="en">
      <head>
        <title>JavaScript Syntax Practice</title>
      </head>
      <body>
        
        <h2>JavaScript Syntax Practice</h2>

        <p id="profile"></p>

        <script>
          // Developer Information
          
          let developerName = "Tanzki"; // Developer's name
          let developerAge = 25; // Developer's age
          let developerCountry = "Philippines"; // Developer's country
          let developerCareer = "Full Stack Developer"; // Developer's career

          /*
            Display Developer Information
            Using console.log()
          */

          console.log("Developer Profile:");
          console.log("-----------------");

          console.log("Name: " + developerName);
          console.log("Age: " + developerAge);
          console.log("Country: " + developerCountry);
          console.log("Career: " + developerCareer);

          // Display Developer Information in the HTML page
          document.getElementById("profile").textContent = "Hello My name is " + developerName + ". I am " +developerAge + " years old from " + developerCountry + ". My goal is to become a " +developerCareer + ".";

        </script>
        
      </body>
      </html>

Final Coding Challenge — JavaScript Code Documentation

Project folder: lesson-04-challenge

Gumawa ng isang mini project na pinamagatang My JavaScript Learning Profile

A. HTML REQUIREMENTS

  • Heading: My JavaScript Learning Profile
  • Paragraph na may ID na profile.
  • Gumawa ng kumpletong HTML structure.
  • Maglagay ng <script> section.

B. JavaScript Requirements

Gumawa ng variables para sa:

  1. Developer Name
  2. Age
  3. Country
  4. Current Skill Level
  5. Dream Career

Pagkatapos:

  • Gumamit ng console.log() para ipakita ang limang impormasyon.
  • Gumamit ng single-line comments para ipaliwanag ang bawat section.
  • Gumamit ng isang multi-line comment para ilarawan ang project.
  • Gumamit ng semicolon sa bawat statement.
  • Gumamit ng maayos na indentation.
  • I-display ang developer information sa HTML gamit ang textContent.

C. Debugging Challenge

Gumawa ng hiwalay na section sa iyong code na may tatlong intentional syntax mistakes bilang comments lamang.

Halimbawa, ilagay ang mga ito bilang text sa comments:

  • Missing quotation mark
  • Missing closing parenthesis
  • Incorrect capitalization

Huwag mong iwan ang mga intentional mistakes bilang active code.Dapat gumagana pa rin ang project mo nang walang syntax errors.
