Exercise 3 — JavaScript Syntax Practice

      File: File: exercise03.html
      <!DOCTYPE html>
      <html lang="en">
      <head>
        <title>JavaScript Syntax Practice</title>
      </head>
      <body>
        <h1>JavaScript Syntax Practice</h1>

        <script>

        /*
          Multi-line comment:
          This is a multi-line comment.
          This program stores a student's information
          and prints it to the console.
        */

        // Single-line comment #1 3 Variables Declaration.
        let developerName = "Tanzki";
        let developerAge = 35;
        let developerDramCareer = "To be a Full Stack Web Developer";


        console.log("Name:" + developerName);
        console.log("Age:" + developerAge);
        console.log("Dream Career: " + developerDramCareer);

        // Single-line comment #2 3 code block using {}.
        {
          let skillLevel = "Beginner";
          console.log(skillLevel);
        }
        

        </script>

          // Code with error
          // Rrror message on Chrome Console

        </script>

          console.log("Hello World");
        </script>

      </body>
      </html>

Final Coding Challenge — JavaScript Developer Information System

File: lesson-04-challenge

Gagawa ka ng maliit na JavaScript project na nagpapakita ng iyong kakayahan sa syntax, statements, at comments.

Project folder:

      lesson-04-challenge/
      └── index.html

A. HTML Requirements

  • Heading: JavaScript Developer Information System
  • Paragraph: Welcome to my programming profile.
  • Five empty paragraphs para sa developer information.

B. JavaScript Requirements

Gumawa ng variables para sa:

  1. Developer Name
  2. Age
  3. Country
  4. Skill Level
  5. Dream Career

Pagkatapos:

  • Gumamit ng console.log() nang hindi bababa sa limang beses.
  • Ipakita ang limang impormasyon sa HTML page gamit ang textContent.
  • Gumamit ng hindi bababa sa limang single-line comments.
  • Gumamit ng dalawang multi-line comments.
  • Gumamit ng isang code block.
  • Gumamit ng tamang semicolon.
  • Siguraduhing walang syntax error.

C. Code Quality Requirements

Hindi lang functionality ang susuriin natin. Susuriin din natin kung malinis at madaling basahin ang code mo. -

Halimbawa, ilagay ang mga ito bilang text sa comments:

  • Consistent ang indentation.
  • Maayos ang variable names.
  • Walang maling capitalization.
  • Kumpleto ang opening at closing tags.
  • Walang unnecessary comments.

Code:

    
Final Coding Challenge — JavaScript Developer Information System
  
      Project folder: lesson-04-challenge
      <!DOCTYPE html>
      <html lang="en">
      <head>
        <title>JavaScript Developer Information System</title>
      </head>
      <body>
        <h1>JavaScript Developer Information System</h1>

        <p>Welcome to my programming profile</p>

        <p id="name"></p>
        <p id="age"></p>
        <p id="country"></p>
        <p id="skill-level"></p>
        <p id="dream-career"></p>

        <script>
          /*
            Lesson 04 Challenge
            Displays developer information on the page using textContent.
          */

          // Developer information variables
          let developerName = "Tanzki";
          let developerAge = 35;
          let developerCountry = "Philippines";
          let developerSkillLevel = "Beginner";
          let developerDreamCareer = "To be a Full Stack Web Developer";
          
          // Log each value to the console
          console.log("Name: " + developerName);
          console.log("Age: " + developerAge);
          console.log("Country: " + developerCountry);
          console.log("Skill Level: " + developerSkillLevel);
          console.log("Dream Career: " + developerDreamCareer);

          /*
            The code block below groups all the statements
            that display the information on the page.
          */
          {
            console.log("Developer information");
            document.getElementById("name").textContent = "Name :" + developerName;
            document.getElementById("age").textContent = "Age :" + developerAge;
            document.getElementById("country").textContent = "Country :" + developerCountry;
            document.getElementById("skill-level").textContent = "Skill Level :" + developerSkillLevel;
            document.getElementById("dream-career").textContent = "Dream Career :" + developerDreamCareer;
            
            // Confirm that the script finished without errors
            console.log("Profile displayed successfully.");
          }
        </script> 
      
      </body>
      </html>
