Exercise 3 — Comparing let, const, and var

File: exercise-03.html

Gumawa ng program na nagpapakita ng pagkakaiba ng tatlong keywords.

Requirements:

  1. Gumawa ng isang variable gamit ang let.
  2. Gumawa ng isang variable gamit ang const.
  3. Gumawa ng isang variable gamit ang var.
  4. I-display ang original values.
  5. I-reassign ang let variable.
  6. I-reassign ang var variable.
  7. I-display ang updated values.
  8. Huwag i-reassign ang const variable.
  9. Gumamit ng comments para ipaliwanag ang bawat keyword.

Additional debugging task:

Gumawa ng hiwalay na test para sa dalawang error:

  • Subukang i-reassign ang const.
  • Subukang i-declare ulit ang parehong let variable sa iisang scope.

I-save ang error messages na nakita mo sa Chrome Console. Ibalik ang code sa tamang kondisyon pagkatapos ng test. 

      
Exercise 3

      
File: index.html

      <!DOCTYPE html>
      <html lang="en">
      <head>
        <title>JavaScript Exercise 3</title>
      </head>
      <body>

        <h1>Comparing let, const, and var</h1>


        <script>
          // `const` declares a variable whose value CANNOT be reassigned.
          const developerName = "Tanzki";

          // `let` declares a variable whose value CAN be reassigned later.
          let developerAge = 35;

          // `var` is the older way to declare a variable. It CAN be reassigned
          var dreamCareer = "JavaScript Developer";

          // Display the original values
          console.log("Name: " + developerName);
          console.log("Age: " + developerAge);
          console.log("Dream Career: " + dreamCareer);

          // The developerName variable uses const, so it will not be reassigned.

          // Reassign the `let` variable (allowed)
          developerAge = 36;

          // Reassign the `var` variable (allowed)
          dreamCareer = "Full Stack Web Developer";
          
          // Display the updated values
          console.log("--- Updated values ---");
          console.log("Name: " + developerName);
          console.log("Age: " + developerAge);
          console.log("Dream Career: " + dreamCareer);
        </script>
        
      </body>
      </html>

Final Coding Challenge — Developer Profile Variable Management System

Project folder: lesson-05-challenge

Gagawa ka ng maliit na Developer Profile System na gumagamit ng let at const.

Gumawa ng webpage na may:

  1. HTML Requirements

    Gumawa ng webpage na may:

    • Heading: Developer Profile Management System
    • Paragraph: My JavaScript Variable Management Project
    • HTML elements para sa:
      • Name
      • Age
      • Country
      • Skill Level
      • Dream Career
      • Learning Status
  2. JavaScript Requirements

    Gumawa ng variables:

    Gamit ang const:

    • developerName
    • developerCountry
    • dreamCareer
    • currentCourse

    Gamit ang let:

    • developerAge
    • skillLevel
    • learningStatus

    Pagkatapos:

    1. I-display ang lahat ng information sa HTML page.
    2. I-display ang lahat ng information sa Console.
    3. I-update ang developerAge.
    4. I-update ang skillLevel.
    5. I-update ang learningStatus.
    6. I-display ulit ang updated information sa HTML page.
    7. Gumamit ng comments para ipaliwanag ang code.
    8. Gumamit ng tamang semicolon at camelCase naming convention.
  3. Additional Challenge

    Magdagdag ng dalawang buttons:

    • Update Skill Level
    • Update Learning Status

    Kapag pinindot ang buttons:

    • Baguhin ang value ng kaukulang let variable.
    • I-update ang HTML output.
    • Ipakita ang bagong value sa Console.

Hint: Maaari mong gamitin ang addEventListener() na natutuhan mo sa Lesson 2.

Hindi mo kailangang gumamit ng bagong concepts maliban sa mga natutuhan mo na. 

      
Final Coding Challenge

      
File: index.html

      <!DOCTYPE html>
      <html lang="en">
      <head>
        <title>JavaScript Final Coding Challenge</title>
      </head>
      <body>
        <h1>Developer Profile Management System</h1>
        <p>My JavaScript Variable Management Project</p>

        <p id="name"></p>
        <p id="age"></p>
        <p id="country"></p>
        <p id="skill-level"></p>
        <p id="dream-career"></p>
        <p id="current-course"></p>
        <p id="learning-status"></p>

        <button id="updateSkillBtn">Update Skill Level</button>
        <button id="updateStatusBtn">Update Learning Status</button>

        <script>

          // Using Const Variable
          const developerName = "Tanzki";
          const developerCountry = "Philippines";
          const dreamCareer = "To become a Full Stack Web Developer";
          const currentCourse = "JavaScript";

          // Using Let Variable
          let developerAge = 35;
          let skillLevel = "Beginner";
          let learningStatus = "Skill Level 1, Lesson 5: Variables let, const, at var";

          // Reassign the `let` variable
          developerAge = 36;
          skillLevel = "Intermediate";
          learningStatus = "Next Skill Level 1, Lesson 6: Data Types";

          // Create a function to display developer information
          function displayDeveloperInfo() {
            document.getElementById("name").textContent =
                "Name: " + developerName;

            document.getElementById("age").textContent =
                "Age: " + developerAge;

            document.getElementById("country").textContent =
                "Country: " + developerCountry;

            document.getElementById("skill-level").textContent =
                "Skill Level: " + skillLevel;

            document.getElementById("dream-career").textContent =
                "Dream Career: " + dreamCareer;

            document.getElementById("current-course").textContent =
                "Current Course: " + currentCourse;

            document.getElementById("learning-status").textContent =
                "Learning Status: " + learningStatus;
          }

          // Display the initial developer information
          displayDeveloperInfo();


          // Display developer information in the console
          console.log("Developer Information");
          console.log("Name:", developerName);
          console.log("Age:", developerAge);
          console.log("Country:", developerCountry);
          console.log("Skill Level:", skillLevel);
          console.log("Dream Career:", dreamCareer);
          console.log("Current Course:", currentCourse);
          console.log("Learning Status:", learningStatus);

          // Update the skill level when the button is clicked
          document.getElementById("updateSkillBtn")
          .addEventListener("click", function () {

            skillLevel = "Advanced";

            displayDeveloperInfo();

            console.log("New Skill Level:", skillLevel);
          });

          // Update the learning status when the button is clicked
          document.getElementById("updateStatusBtn")
          .addEventListener("click", function () {

            learningStatus = "Next Skill Level 2, Lesson 13: if Statement";

            displayDeveloperInfo();

            console.log("New Learning Status:", learningStatus);
          });

        </script>
        
      </body>
      </html>
