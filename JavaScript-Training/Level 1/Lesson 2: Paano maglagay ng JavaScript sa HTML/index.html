Paglalagay ng JavaScript sa HTML

Exercise 1 — Inline JavaScript

Gumawa ng sariling files sa VS Code. Huwag munang kopyahin ang solution mula sa akin.

Requirements:

  1. Gumawa ng HTML webpage.
  2. Maglagay ng heading na Inline JavaScript Practice.
  3. Gumawa ng button.
  4. Gumamit ng onclick.
  5. Kapag na-click ang button, dapat magpakita ng alert message.
      <h1>Inline JavaScript Practice</h1>
      <button onclick="alert('Hello World!')">Alert Button</button>

Exercise 2 — Internal JavaScript

Requirements:

  1. Gumawa ng HTML webpage.
  2. Gumawa ng button na may ID na myButton.
  3. Ilagay ang JavaScript sa internal <script> tag.
  4. Gamitin ang document.getElementById().
  5. Gumamit ng addEventListener().
  6. Kapag na-click ang button, dapat magpakita ng alert message.
  7. Mag-display rin ng message sa Console.
      <h1>Internal JavaScript Practice</h1>
      <button id="myButton">Alert Buttin</button>

      <script>
      document.getElementById("myButton").addEventListener("click", function () {
        alert("Hi! My name is Tanzki and I Love To CODE!");
        console.log("Hi! My name is Tanzki and I Love To CODE!");
      });
      </script>

Exercise 3 — External JavaScript

Requirements:

  1. Gumawa ng index.html.
  2. Gumawa ng js folder.
  3. Gumawa ng script.js sa loob ng js folder.
  4. Ikonekta ang JavaScript gamit ang tamang file path.
  5. Gumamit ng defer.
  6. Gumawa ng button.
  7. Kapag na-click ang button, magpakita ng alert.
  8. Mag-display ng tatlong messages sa Console.
      Exercise-03/index.html
      HTML Code:
      <html>
      <head>
      <title>JavaScript Connection Test</title>
      </head>
      <body>

        <h1>External JavaScript Practice</h1>
        
        <button id="clickMe">Click Me!</button>

      <script src="js/script.js" defer></script>
      
      </body>
      </html>
      
      Exercise-03/js/script.js
      JavaScript Code:
      document.getElementById("clickMe").addEventListener("click", function () {
          alert("Button Clicked!");
          console.log("First message:");
          console.log("Second message:");
          console.log("Third message:");
      });

Challenge: JavaScript Connection Testing System

Gumawa ng mini website na susubok kung tama ang coonction ng HTML at JavaScript.

Requirements:

HTML (index.html)

  • Page title: JavaScript Connection Test
  • Heading: JavaScript Connection Testing System
  • Paragraphna napapaliwanag ng project.
  • Button na may ID na testButton.
  • External JavaScript connection
  • Gumamit ng defer.

JavaScript(apps.js)

  • Mag-display ng limang messages sa Console.
  • Gumamit ng document.getElementbyID().
  • Gumamit ng addEventListener
  • Kapag na-click ang button. mag-display ng alert.
  • Mag-display ng confirmation message sa Console kapag na-click ang button

Additional Challeng

  1. Test JavaScript Connection
  2. Test Button event

Dapat magkaiba ang behavior ng dalawang buttons.

      Challenge/index.html
      HTML Code:
      <html>
      <head>
      <title>JavaScript Connection Test</title>
      </head>
      <body>

      <h1>JavaScript Connection Testing System</h1>
      
      <p>
        Ang page na ito ay ginawa para subukan ang pagkakonekta ng html file sa JavaScript file.
      </p>

      <button id="testButton">Test JavaScript Connection</button>
      <button id="eventButton">Test Button Event</button>

      <script src="js/script.js" defer></script>
      
      </body>
      </html>

      Challenge/js/script.js
      JavaScript Code:
      console.log("Message 1: Nakakonekta na ang app.js.");
      console.log("Message 2: Gumagana ang defer.");
      console.log("Message 3: Na-load na ang buong HTML bago tumakbo ang script.");
      console.log("Message 4: Handa nang tumanggap ng click events.");
      console.log("Message 5: Matagumpay ang JavaScript connection test!");

      document.getElementById("testButton").addEventListener("click", function() {
          alert("Test Button Clicked!");
          console.log("Connection Successful.");
      });

      document.getElementById("eventButton").addEventListener("click", function() {
          alert("Event Button Clicked!");
          console.log("Event Function Successful.");
      });
