Final Coding Challenge:

Student Grading and Eligibility System

Gumawa ng JavaScript program para sa student grading system.

Requirements:

  1. Gumawa ng variables:
    • studentName
    • age
    • grade
    • attendance
  2. Gumamit ng if, else if, at else.
  3. Grade classification:
    4.             Grade	        Result
            95–100	      Outstanding
            90–94	        Excellent
            85–89	        Very Good
            80–84	        Good
            75–79	        Passed
            Below 75	    Failed
  4. Registration eligibility:
    • Age must be 18 pataas.
    • Attendance must be 80 pataas.
    • Grade must be 75 pataas.
  5. Kapag hindi eligible, ipakita ang dahilan kung bakit hindi qualified.

Expected Output example:

          ================================
                STUDENT REPORT
          ================================

          Student Name: Tanzki
          Age: 25
          Grade: 92
          Attendance: 95%

          Grade Classification: Excellent

          Registration Status: Eligible
